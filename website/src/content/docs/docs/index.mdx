Queditor is a terminal Markdown and text editor with an integrated assistant.
Live Agent edits apply and save automatically, then appear in an editable unified
diff. Keep confirms them; Undo reverts and saves them. Chat mode is read-only, and
offline mock demonstrations remain unsaved previews.

:::caution[Pending edits are already on disk]
Review before publishing or synchronizing. Automatic saves include existing unsaved
text; Undo cannot reverse external effects. Unnamed documents use private temporary
backing; Ctrl+S chooses a real filename for subsequent automatic saves.
:::

:::caution[Early prototype]
Offline mock mode is the default. Live AI requires provider configuration, and
the downloadable binaries are currently unsigned.
:::

## Start here

## Install from source

With a current stable Rust toolchain:

```sh
cargo install --git https://github.com/merlos/queditor
queditor document.md
```

You can also download an archive from [GitHub Releases](https://github.com/merlos/queditor/releases).
Verify its SHA-256 checksum before running it.
